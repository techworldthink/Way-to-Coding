# Instructor Guide

## Teaching style

This is a coding workshop, not a lecture.

Recommended rhythm:

```text
5–10 min explanation
      ↓
Instructor writes code
      ↓
Students write code
      ↓
Run/test
      ↓
Move on
```

## Do not spend workshop time on

- advanced Django internals
- class-based views
- REST Framework
- React
- Docker
- PostgreSQL
- deployment
- advanced JavaScript

Those are suitable for a follow-up workshop.

## If students are behind

Skip the optional dashboard styling and Git discussion temporarily.

Prioritize:

```text
Django setup
Model
URL
View
Template
Form
CRUD
Authentication
```

## If students finish early

Give:
- search
- priority
- category
- due date
- sorting
- dashboard statistics
- responsive improvements

## Final learning objective

Students should understand that a full-stack application is not one technology.

It is a connected system:

```text
Frontend
   ↕
Backend
   ↕
Database
```

Django helps connect these pieces.
