# 3-Day Full Stack Development Workshop

**Duration:** 3 Days × 1.5 Hours
**Technology:** Python + Django + HTML/CSS + SQLite
**Approach:** Practical, project-based

## Day 1 — Build the Foundation

**Topics:**

* What is Full Stack Development?
* Basic web application flow
* Django introduction
* Create Django project
* Django app structure
* URLs, Views & Templates
* Create a simple database model
* Run migrations
* Display database data

**Practical:**
Start building the application and display records from the database.

**Homework:**
Add a few sample records and make one small change to the model/UI.

---

## Day 2 — Make It Interactive

**Topics:**

* Django Forms
* CRUD concept
* Create records
* Edit records
* Delete records
* Basic Bootstrap styling

**Practical:**
Complete the main CRUD functionality of the application.

**Homework:**
Add one small feature such as search, filter, category, or priority.

---

## Day 3 — Login + Complete Application

**Topics:**

* User registration
* Login & logout
* Protecting pages
* User-specific data
* Basic dashboard
* Git & GitHub

**Practical:**
Add authentication and finish the application.

**Final Outcome:**

```text
Login
  ↓
Dashboard
  ↓
Create
  ↓
View
  ↓
Edit
  ↓
Delete
  ↓
Logout
```

**Final Homework:**
Add 1–2 additional features and push the project to GitHub.

### Overall

```text
DAY 1 → Django + Database
DAY 2 → CRUD + UI
DAY 3 → Login + Final Application
```
