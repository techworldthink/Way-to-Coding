# Course Overview

## Day 1 — Build the Foundation

- What is Full Stack Development?
- Basic web application flow
- Django introduction
- Create Django project
- Django app structure
- URLs, Views & Templates
- Create a simple database model
- Run migrations
- Display database data

**Practical:** Start the application and display records from the database.

**Homework:** Add sample records and make one small model/UI change.

## Day 2 — Make It Interactive

- Django Forms
- CRUD concept
- Create records
- Edit records
- Delete records
- Basic Bootstrap styling

**Practical:** Complete the main CRUD functionality.

**Homework:** Add one small feature such as search, filter, category, or priority.

## Day 3 — Login + Complete Application

- User registration
- Login & logout
- Protecting pages
- User-specific data
- Basic dashboard
- Git & GitHub

**Practical:** Add authentication and finish the application.

**Final homework:** Add 1–2 additional features and push the project to GitHub.
