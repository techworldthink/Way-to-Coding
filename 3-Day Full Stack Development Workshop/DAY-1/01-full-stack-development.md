# 1. What Is Full Stack Development?

A web application normally has a frontend, backend and database.

```text
Browser → Frontend → Backend → Database
```

**Frontend:** what the user sees and interacts with. We use HTML, CSS and Bootstrap.

**Backend:** application logic. We use Python and Django.

**Database:** stores application data. We use SQLite.

Our project is a Task Manager. A task has a title, description, completion status and creation date.

By the end of the workshop, users will be able to register, log in and manage their own tasks.
