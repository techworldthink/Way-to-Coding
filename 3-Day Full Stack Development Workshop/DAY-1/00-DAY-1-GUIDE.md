# Day 1 — From Python Environment to First Database Page

## Day 1 objective

By the end of Day 1 you will:
- create a virtual environment
- install Django
- create a Django project
- create a Django app
- understand project/app structure
- create a database model
- run migrations
- use Django Admin
- connect URL → view → database → template
- display real database records in a browser

## 90-minute plan

| Time | Activity |
|---|---|
| 0–10 | Full-stack and Django concepts |
| 10–25 | Python venv and Django installation |
| 25–40 | Project and app |
| 40–55 | Model and migrations |
| 55–65 | Admin |
| 65–85 | URL/view/template |
| 85–90 | Test and homework |
