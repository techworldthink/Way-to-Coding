# Day 1 Practical

## Goal
Build the foundation and display database records.

Checklist:

- [ ] Python and virtual environment
- [ ] Django installed
- [ ] Project created
- [ ] `tasks` app created
- [ ] App added to settings
- [ ] URL created
- [ ] View created
- [ ] Template created
- [ ] Task model created
- [ ] Migrations run
- [ ] Admin configured
- [ ] Sample records created
- [ ] Records displayed

## 90-minute guide

10 min — Full-stack/web flow  
15 min — Django setup  
15 min — Project/app structure  
20 min — URLs, views, templates  
15 min — Model/migrations  
10 min — Display database records  
5 min — Homework
